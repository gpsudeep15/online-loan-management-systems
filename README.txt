ONLINE LOAN MANAGEMENT SYSTEM

How to run:
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or open it with Chrome/Edge/Firefox.
4. Register a customer account and log in.
5. Admin login:
   Email: admin@loan.com
   Password: admin123

Features:
- Customer registration and login
- Loan application form
- EMI calculator
- Customer loan application tracking
- Admin dashboard with search, approve and reject actions
- Responsive layout for mobile and desktop

Important:
This is a front-end college-project demonstration. Data is stored in the browser's
localStorage on that device/browser. It is not a secure production banking system.
For a real system, use a PHP/backend server, database, password hashing, and
server-side authentication/authorization.
